# Romania institutional checklist, version 1.28.0

This is a **partial** national and county release for all six Nexsteps institutional sectors and all eight tracker topics. It is a manual planning checklist, not a legal certificate. The site's actual operator, educational authorisation, ages, activities and location determine applicability; the portal's ACE, Church, Charity, School or Learning Centre screen does not.

## Territorial review

[Eurostat's NUTS 2024 attributes](https://gisco-services.ec.europa.eu/distribution/v2/nuts/csv/NUTS_AT_2024.csv) identify 42 county-level `Județe` selectors, including Bucureşti. The additive migration copies those exact codes and names. The county checklist action asks an actual school to identify the competent inspectorate and operating municipality; it does not assert that Eurostat grants permission. [INS SIRUTA S1 2026](https://data.gov.ro/en/dataset/siruta_s1-2026) is the intended current municipality source, but its download timed out during review. Eurostat's 3,181 LAU 2025 count is useful cross-check evidence, not proof of each current SIRUTA code, name or parent. Municipality selectors and municipality-specific duties remain **in review**.

The catalogue marks all Romania country cells `PARTIALLY_PUBLISHED`. Only county registration cells have a reviewed entry action; the other county cells remain `IN_REVIEW`. Regional and municipal gaps remain visible in the tracker. Confirm uncertain applicability with the competent county inspectorate, DGASPC, ISU, DSVSA or local authority before recording an exception. The manual checkbox does not change when a portal signal changes.
