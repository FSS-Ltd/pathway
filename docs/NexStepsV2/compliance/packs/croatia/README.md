# Croatia national checklist pack (2.09)

Reviewed 2026-10-18. Catalogue 1.10.0 adds **16 conditional actions** and **18 official/provider sources** across six institutional coverage sectors and eight topics. It publishes a partial national and EU core; all 48 Croatia cells remain `PARTIALLY_PUBLISHED` with regional status `IN_REVIEW`. Manual checklist completion is not legal certification.

The [government private-school establishment route](https://gov.hr/hr/osnivanje-privatnih-osnovnih-skola-srednjih-skola-i-ucenickih-domova-u-republici-hrvatskoj/1382) differs from [kindergarten establishment](https://gov.hr/?id=1381&url=print) and [shorter preschool programmes](https://gov.hr/en/shorter-educational-programmes-with-pre-school-children/982). The pack asks every site to classify actual provision. Only an actual independent school receives the private-school start action. A young-child learning centre receives a shorter-preschool _review_ action; age alone does not establish that it operates a regulated preschool programme. A school/ACE screen set does not establish legal status.

The [Ministry of the Interior's reporting route](https://mup.gov.hr/online-prijave/281666) and [child-abuse protocol](https://mup.gov.hr/online-prijave/online-prijava-zlostavljanja-djeteta-red-button/sto-ce-policija-uciniti/protokoli/281712) support a safeguarded referral process. [Employer safety guidance](https://gov.hr/en/basic-occupational-safety-obligations-of-employers/1372) covers written risk assessment, training and first aid. [EU GDPR](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng) and the [Croatian regulator's guidance](https://azop.hr/obligations-of-organisations/) depend on processing roles. The [State Inspectorate food register](https://dirh.gov.hr/o-drzavnom-inspektoratu-9/ustrojstvo-77/7-sektor-sanitarne-inspekcije/evidentiranje-i-vodjenje-registra-subjekata-i-pripadajucih-objekata-u-poslovanju-s-hranom-iz-nadleznosti-sanitarne-inspekcije/431?impaired=1) and EU hygiene law are conditional on actual food activity. ICCE terms apply only to qualification providers.

The [county and Zagreb inventory](regional-review.md) lists unresolved local rules. School and preschool programme details, role-specific checks, premises permissions, trips and specialist food approvals still need authority review. Site managers should confirm uncertain applicability with the competent local authority before marking a review action not applicable. No automatic checkbox completion, UI change or database migration is introduced.
